Implement synthesizable SystemVerilog with this exact interface:
module TopModule(input clk, input reset, input in_valid, input [7:0] in_data,
                 output in_ready, output out_valid, output [7:0] out_data,
                 input out_ready);
This is one registered storage slot with ready/valid handshakes, not a
combinational bypass. reset is synchronous active high and empties the slot.
out_valid equals slot occupancy. out_data equals stored data when occupied,
and 8'h00 when empty. in_ready = !out_valid || out_ready, including when
reset=1 (do not combinationally gate any output with reset).
On a rising edge reset has priority. Otherwise, if in_ready is high, update
occupancy to in_valid and store in_data if in_valid=1. Otherwise retain the
occupied slot and its data regardless of in_valid/in_data changes.
Thus a full slot can be consumed and replaced on the same edge with no bubble;
empty+in_valid is visible at the output only after that edge.
