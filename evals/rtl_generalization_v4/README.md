# V4 新增独立开发题

本题集在读取任何 V3/V4 新生成候选之前编写，冻结后只向生成端提供 `prompts/<task_id>/prompt.txt`。`evaluator/`、本生成器、参考实现、变异体和固定测试台只能供独立评测使用，不能进入智能体或模型上下文。

六题为原创开发测试，覆盖了旧题中的一般问题类别，但改变了接口、字长、分组长度、采样沿或协议。它们不是官方隐藏题，单次测试不能当作正式 pass@1 或比赛分数。

| 题目 | 核心要求 | 固定检查数 | 预置错误变异体 |
| --- | --- | ---: | --- |
| v4_01_rotate12 | 12 位循环位移、距离 0..15 按 12 取余 | 131072 | 左移漏回填 |
| v4_02_signed_addsub6 | 6 位补码饱和加减、精确上下界 | 8192 | 减法变加法 |
| v4_03_negedge_mod7 | 下降沿、异步低复位、七次使能才回绕 | 846 | 提前一拍回绕 |
| v4_04_group_sum3 | 每三次有效输入求和、当前输入参与结果 | 1041 | 漏加第三个样本 |
| v4_05_enabled_1101 | 重叠序列、暂停历史、脉冲清除 | 2687 | 暂停保持脉冲 |
| v4_06_readyvalid_fifo2 | 深度 2、5 位 FIFO、满时同拍替换、空时无直通 | 1226 | 满时错误拒绝替换 |

固定测试台有独立整数、比特索引、完整有效历史或队列模型，并与 `RefModule` 交叉核对。参考实现与模型不一致时报 `ORACLE_ERROR`，不能视为候选设计失败。测试必须走完整激励才打印唯一 `Mismatches: N in M samples`；提前 `$finish` 不会被误判通过。

2026-10-22 本地 Icarus 13 预检：6/6 参考实现通过，共 145064 次检查；6/6 变异体成功编译且全部被功能测试拒绝。预检时曾修复两个测试台在手动异步复位结束后留下旧使能、出现模型未计入的额外时钟更新的问题，最终冻结版本在复位检查前令驱动保持空闲。该修正发生在模型候选生成之前，不是迁就候选输出修改期望。

复现：从工程根运行 `python scripts/evaluate_suite.py --suite evals/rtl_generalization_v4 --output <新的结果目录> --validate-fixtures`。Icarus 路径通过 `IVERILOG_BIN` 配置。`build_fixtures.py` 仅复现题目与评测文件；它不会生成智能体答案、调用模型或进入智能体执行路径。`freeze-manifest.json` 为静态题目、参考和脚本的逐文件 SHA-256，排除 `preflight/` 运行产物。
