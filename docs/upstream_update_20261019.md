## 本次改变

| 项目 | 原状态 | 当前实现 |
| --- | --- | --- |
| 投题 | 同步等待解题完成 | 立即 HTTP 202，返回 job_id，查询 `/v1/jobs/<id>` |
| 重复请求 | 没有 nonce 去重 | 同一非空 nonce 返回原任务，含完成后的重复投递 |
| 并发与计时 | 忙时拒绝新请求 | 串行队列，排队计入单题预算；过期不启动解题 |
| 单题默认预算 | 180/360 秒 | 各入口统一 900 秒；服务预留终止与返回时间 |
| 基线 | 9 月旧参考文件 | 官方 f7a8bd4 Git 对象原样；16384 token、840 秒请求超时 |
| 思考模式 | DeepSeek 开发专用字段 | 本地模型与基线共读 manifest generation；DeepSeek 专用设置仅用于开发 |
| 输出提取 | 可能把思考中代码当答案 | 剥离完整/仅结束标记/截断的 think 段 |
| 候选保存 | 直接写文件 | 原子替换，保留最好的已有候选 |
| 常驻推理 | 仅 vllm 启动脚本 | `serve/start.sh` 通过 setsid 拉起，等待模型就绪，允许重复执行 |
| Linux 中间文件 | 可能写入网络输出盘或 /tmp | EDA_TMP 独立目录，保留证据后清理；默认 /var/tmp |
| Linux 子进程 | EDA 可脱离单题组 | EDA 继承单题组；服务清扫任务组并回收后代 |
| 文档与声明 | 旧协议/基线记录 | 更新启动说明、模型配置、时间节点和协作记录；历史成绩保留日期 |

官方基线从 Git 提交对象复制，使用 LF 换行以便 Linux 执行，未定制提示词或判分逻辑。
内置 `tasks/README.md` 随上游同步；公开题源码、参考测试台和判定器内容没有变化，继续原样保留。
生成智能体只读题面与可选接口，仍不接触参考答案或参考测试台。

本轮没有调用真实商业模型，没有产生新的盲测能力或增益成绩。测试证据保存在
`runs/upstream_update_20261019/`；实际结果完成后记入下节。
