## 测试条件

- 模型：商业 API `deepseek-flash`，关闭 thinking；权重 revision 不可由本次客户端核验。它与此前云端 Qwen3-14B-Q4_K_M 是不同模型，不能将此前的 3/6 与本轮 6/6 直接作提升比较。
- 三组：无 skill 单次生成开发对照 `plain_api`、冻结 V2、冻结 V3。每道题每组一次，共 **18 个独立生成样本**，未固定采样 seed，没有挑最好一次。
- V2/V3 使用 temperature=0.2、单题 240 秒、最多 3 轮。裸模型使用 temperature=0、单次调用、240 秒和 16384 输出 token；不加载 skill，不调用自检或修复。裸对照沿用官方 SYS 提示与提取函数，但通过自定义带鉴权客户端连接商业 API，**不是官方 baseline 进程或正式基线成绩**。官方 baseline 文件未修改。
- 题集：用户提供的六道补充练习；属于开发题，参与过历史分析，不是新的保留盲测题。生成端只接收各自 `prompt.txt`；固定测试台、参考实现不进入模型消息。
- 判定：Icarus Verilog 13.0，固定独立测试台。参考预检六题通过，共 24,129 个检查点；要求完整完成测试及有效 PASS，失配和未知态均拒绝。

## 两个关键发现

**V2 序列检测器是自检误报通过。** 它将最新输入放入 `next_hist[3]`，却按相反的时间方向判断匹配；自建 TB 对历史位序也有误解，因而没有检出错误。固定测试台在 `check=5, reset=0, in=1` 得到 `detected=0`，期望为 1。V3 明确三位旧历史的时间顺序，并把当前输入参与本拍判断，完整通过 2830 个检查点。

**V2 奇偶校验器是自检误报失败。** DUT 实际通过固定测试台的 6357 个检查点。其自建 TB 先用阻塞赋值把当前位异或进 `ref_xor`，生成结果时又异或当前位一次。诊断返回 `testbench_error`，流程保留正确候选而没有改 DUT。V3 本轮自建 TB 没有出现这一重复计算，内部和独立测试均通过。

18 份最终候选均来自首次 DUT 生成。V3 的格式恢复、编译修复和 DUT 修复分支本轮均未触发；这轮结果不能证明这些恢复分支带来了功能增益。它们的行为证据仍是此前的 105 项本地回归。

## 对 skill 收益的判断

V3 相对 V2 本轮多通过 1/6 题，即观察差异为 16.7 个百分点；相对裸模型是 0 道、0 个百分点。V3 累计生成耗时约为裸模型的 3.7 倍。样本仅一次，且修改包含设计提示、规则、验证提示与执行接线，无法单独归因于规则文本或证明稳定的因果提升。

这组简单题对裸 DeepSeek 已出现通过率上限。目标 Qwen 的后续同轮测试已在新增 1 积分内完成：官方基线 3/6、V2 3/6、V3 4/6，见 [Qwen 实测报告](v3_qwen_test_20261022.md)。本报告的 DeepSeek 阶段没有启动云实例；两个模型的结果分开记录，正式能力/增益仍需多次独立采样与官方判级。
