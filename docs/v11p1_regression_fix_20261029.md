V11的默认无独立行为规划、明确文字接口解析和复位X/Z盲复核流程继续保留。历史V10通过仲裁的样本中，行为规划状态本来就是`invalid_or_error`，首稿被选中；现有证据不足以把丢题归因于取消规划，故不加回额外调用。仲裁两个版本都有循环变量声明初始化，不能把共有的工具警告说成V11独有根因。

归档重放有一个明确限制：优先编码器回复的`expected=000`与理由中“应为7”矛盾，实际输出7正确。规范化后，V10和V11.1数值归因均会错误指向DUT，不能把这条算成语义改善。另一计数器回复`0000`符合实际复位与保持历史，恢复为`testbench_error`。这两题在原V11独立判定中均已L3；修复格式不能算作新增通过两题。
