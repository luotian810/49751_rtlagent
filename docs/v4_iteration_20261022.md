## 从反复出现的问题到通用修改

| 问题类别及实测证据 | V4.2 的一般处理 |
| --- | --- |
| 模型反复在语句后声明变量、过程写 wire、局部变量遮蔽输入；编译修复后仍出现同类错误 | 模型只交 JSON 验证计划；固定生成器集中声明输入、输出、私有变量、task 参数，统一具名例化。片段中禁止新声明或自建进程，不依赖模型重复手写完整 TB |
| 自由运行时钟、驱动与采样竞态、固定上升沿检查与下降沿规格冲突 | 计划显式给出有效采样沿，每个 `step` 驱动一次输入、满足建立时间、触发一次有效沿，在 NBA 稳定后检查，再回到非有效电平。声明了异步复位时还在有效沿前检查复位输出 |
| 旧状态与更新后的状态混用，当前输入漏算或重复计入；V4/V4.1 又反复写错显式 `old_ref_` 前缀 | 原生 `advance` 改为 `temporary`/`next`/`writes` 表达式映射。程序自动读取旧状态、计算组合临时量、计算所有下一状态，再同时提交；模型不再手写快照前缀。数组按条件写入，未写元素保持；复位统一恢复变量声明的 `initial`，不让每条更新重复手写复位 |
| V4 完整 JSON 缺失，V4.1 刺激向量误把时钟计入参数，参考更新的代码片段仍脆弱 | 刺激改为有限的 directed/repeat 与 random/cycles 数据，`values` 按非时钟输入的端口名映射，程序校验键并排序驱动。更新只允许表达式，不再让模型手写赋值语句与控制循环；结构或编译恢复仍共享一次机会 |
| 无有效检查却打印通过、正常结束与看门狗竞争、种子无效；实际值和期望值同时为 X 可能相等 | 固定骨架统一种子、最小检查数、失败日志、PASS 和看门狗；实际值或期望值含 X/Z 时单独判失败，再做逐输出比较，不能将双方未知算作通过 |
| 自建参考模型也会误解位序、更新顺序或规格，形成误报通过/失败 | 验证生成仍只看规格，不看 DUT；一旦功能失配，保留固定测试台先归因，无法确定时停止，不改期望迎合 DUT。另用模型从未见过的固定测试台独立判定 |
| 循环移位丢回填、非二次幂距离处理错误、计数回绕与分组边界错误；仅有 TB 骨架不能修正设计语义 | 设计规则检查位来源、常量、N−1/N/N+1 和实际握手；首稿后增加一次只依据规格与 DUT 的独立设计审查。审查发生在 TB 生成前，不看外部答案。改稿必须得到更强的仿真证据才替换原已编译候选，不凭审查意见或同级编译覆盖 |

核心实现为 [verification_plan.py](../agent/verification_plan.py)，默认入口选择 `--verification-mode structured`；`legacy` 保留作旧流程回归对照。模型仍负责全部 DUT 设计、参考算法和测试序列，脚本负责结构验证与调度，没有硬编码硬件答案。官方 `baseline.py`、`run_baseline.sh` 不参与这些改动，继续原样保留。

计划的端口会与题面接口核对，期望表达式必须覆盖每个输出。算法不能访问 DUT 输出、层次信号、外部文件或系统命令，也不能自行控制时序与结束。旧字符串计划仅保留读取兼容，新模型提示要求表达式映射与具名刺激数据。结构限制不构成对参考算法语义正确性的证明。

## 能力边界与本轮口径

当前骨架支持纯组合或单时钟、单有效采样沿、普通 input/output 端口，可声明一个异步复位。多时钟、双边沿交互、inout 等超出当前格式，需要明确返回 unsupported；不能把未完成验证算通过。复杂延迟与协议仍需由模型在参考状态中准确表达。

快照机制避免一种旧/新状态混用，但模型仍可能选择错误终值、位序、复位优先级或参考算法。最小检查数也不保证刺激覆盖充分；自检通过只表示该计划通过，独立固定功能测试仍是本轮能力判断依据。

本轮 V4 至 V4.2 **新增云积分开销为 0**，未启动新云实例；此前新增的 1 积分已经在 V3 Qwen 验证中用完。商业 API 开发测试与正式离线 Qwen 测试分开记录，不把 API 结果写成 Qwen 提升，也不沿用旧显存测量冒充新测量。API 费用不属于云积分，未测量账户实际扣款。

剩余问题已从测试台结构转到模型语义：计数器参考算法遗漏同步清除优先级；FIFO 参考把深度 2 的满阈值写成 3。FIFO DUT 另外存在同一过程对占用量的多次非阻塞赋值，同时读写时后一次覆盖前一次，以及数组索引未限制在合法范围的问题。诊断的标签与值还会矛盾，因此流程保守停止，没有修改测试期望来放行。这些应按“控制优先级、容量边界、同拍接受事件与状态净变化”这一类问题继续研究，不能只给当前 FIFO 题塞答案。

最终骨架的三项受控用例在本机 Vivado 2025.2 仿真通过：组合临时量扩位、分组状态同时更新、FIFO 数组写入。六份最终模型 RTL 另行执行一次真实综合，日志见证据目录 `synthesis-v42/`；综合不能替代功能判定，也没有布局布线或时序收敛结论。
