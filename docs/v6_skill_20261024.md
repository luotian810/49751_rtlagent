# V6 通用 skill 优化与本地验证

2026-10-24，RTL track。本记录保存 V6 的代码与本地机制回归阶段；该阶段未调用真实模型或启动云实例。随后已完成固定 Qwen3-14B-Q4_K_M 的 21 个新样本测试，结果与费用见 [V6 千问测试报告](v6_qwen_test_20261024.md)，不与本地机制测试混算。

## 依据与取舍

[V5 同批千问测试](v5_qwen_test_20261023.md) 为官方基线 7/21、V4.2 8/21、V5 8/21，两版智能体通过同样的 8 题。V5 减少了调用和耗时，但仍会生成错误参考算法、漏掉初态、误解采样顺序或保留编译错误。因此，本轮把改进放在跨设计成立的接口、状态、表达式和反馈规则上。

不在运行时加入题名判断、固定答案、题型公式或按公开参考挑选候选。设计与修复仍由同一千问模型完成；独立验证只接收规格、契约和相关诊断。已看过的 21 题只能作开发回归，不能再声称是未见题集。

## 改了什么

| 共性问题 | V6 改动 | 边界 |
| --- | --- | --- |
| 接口漂移、字段遗漏 | 从规格可靠提取的端口契约同时传给设计与修复；验证计划获得输入占位模板；错误明确指出字段路径、缺失和多余名字 | 参数位宽无法可靠解析时不猜测；保留题面原声明、范围和参数；模板空字符串是待填项 |
| 位宽截断、混合符号、非法切片或类型 | 精简设计规则，要求先扩位并明确符号，再运算和截断；区分普通常量切片与固定宽度的动态索引切片，检查枚举赋值类型 | 由模型按规格落实；没有新增题型求解器，也没有声称接口检查器可证明全部符号语义 |
| 正确 DUT 因初态未知被误判 | 结构化计划明确声明 reset 时，骨架先执行一次实际复位 step，再执行原有刺激；按声明的极性和采样沿工作 | 前置向量将其他非时钟输入置 0；这是新增初始化向量，原刺激缺键仍报错，不静默补齐 |
| 参考状态及输出错拍 | 明确 step 顺序：驱动输入→按旧状态计算临时量→同时更新参考状态并计算 expected→触发 DUT 采样沿→等待 NBA 稳定并比较；临时量不在沿后重算 | expr/next/writes 读旧状态，expected 读新状态；异步复位另有沿前检查；无时钟电路不加时钟 |
| 编译修复丢失根因 | 优先保留前 8 条去重 error/fatal 行，限制反馈长度；没有匹配诊断时保留日志尾部 | 原始工具日志继续完整保存；不增加修复次数 |

两个运行时规则文件从 1555 个非空白字符减为 1390 个，减少约 10.6%。这是字符量比较，**不是 Qwen token 数或端到端速度实测**。入口继续按设计/验证职责加载相应规则，不把所有说明重复塞进每次调用。

自动复位只适用于结构化计划已经支持的明确复位、单时钟参考模型。它按声明的 initial 建立参考状态，不能证明 initial 符合题意；无复位未知初态、多时钟、需要多周期初始化或当前计划无法表达的语义不因此获得支持。旧完整 TB 流程仍自行初始化。参考算法语义错误也仍可能误拒绝正确 DUT，自检 PASS 不代替官方判定。

## 本地验证

完整回归 **185 项通过、0 失败、0 错误、0 跳过，19.109 秒**。新增的 `tests/test_skill_v6.py` 包含 12 个测试方法；采用受控模型回复和真实本地 Icarus，未调用千问。这些结果验证机制行为，不是模型能力测试。

- 更换端口名称、位宽及符号，确认契约按规格生成、未知位宽不猜测，缺键与多余键准确报错。
- 在设计/修复间保持同一固定契约，并确认验证消息不包含 DUT、外部参考实现或测试台中的哨兵内容。
- 用寄存采样电路验证 2 种位宽 × 2 种采样沿 × 2 种复位极性 × 同步/异步，共 **16 种组合**，包含非零复位值及首个刺激不复位的情况。
- 删除前置复位可复现正确 DUT 因未知初态被误拒绝；保留前置复位仍可检出错误使能、错误采样沿以及用同步复位冒充异步复位的变异实现。
- 组合电路没有额外复位或时钟步骤；禁止读取输出和禁止函数的约束继续生效；长日志仍能保留早期编译错误。

skill 的名称、描述和引用路径已检查。`skill-creator` 的 `quick_validate.py` 因本机缺少 PyYAML 未运行成功，未为此安装新依赖；不能把手动结构检查写成该工具通过。
