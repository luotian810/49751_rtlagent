## 失败与修复闭环

- 序列检测：V3 用旧三位历史与本拍输入一起判断，正确包含当前位，没有多延迟一拍；通过 2830 个固定检查点。
- 循环移位：V3 消除了窄常量模零，但仍用先移位、再反向移动整 8 位的表达式，没有实现回填。首个失配为 in=01、amount=0、right=0，实际 00、期望 01。
- 奇偶校验：V3 比较旧 bit_count==8，使 valid 没在第 8 个有效输入后拉高；结果计算还读旧 data。首个失配 check=16，期望 valid=1、实际 0。
- 两版内部自检均 0/6；V3 仍有五题停在测试台编译错误，另一题因诊断 uncertain 停止。常见 TB 错误为语句之后声明 seed/局部变量、非法动态范围切片等，语法修复没有使这些 TB 可靠运行。
- V3 约 381.039 秒用于 TB 生成和恢复，占累计生成墙钟约 82%。六份最终 DUT 均与首轮相同，DUT 修复调用为 0；新增通过来自本轮首稿，不能归功于修复闭环。
- 本轮为 4/6 相对 3/6 的观察差异（+1 题、+16.7 个百分点），没有多次独立采样或单独规则文本消融，不能证明稳定提升。
