# 独立验证检查清单

只从规格建立独立参考算法，不接触 DUT 源码或外部答案。

1. 按当前 JSON 契约填写采样控制、参考算法与刺激；固定端口由程序提供。临时量声明/expr、状态声明/next（数组用 writes）各自写在同一记录。按字段路径和允许名字修复格式，不改变算法含义；仅旧 TB 流程自行编写骨架。
2. 时钟采样沿、复位极性/同步性与状态 initial 均须来自规格。结构化计划声明 reset 后，模板先执行一次复位 step，再运行定向和随机刺激；initial 是复位值，不能选取方便测试的值。旧 TB 流程自行建立同样的初态。无复位时，参考变量初始化不代表 DUT 初态已知；无法按规格建立可检查初态则明确说明不支持（结构化计划返回 unsupported）。
3. step 先驱动输入、计算临时量，再按旧状态同时更新全部参考状态并计算 expected；有时钟时触发规定沿，等待 NBA 稳定后比较。expr/next/writes 读旧状态，expected 读新状态。临时量按列表顺序只算一次，沿后组合输出直接用新状态计算。组合电路不引入时钟；不自行添加边沿或延时。
4. 参考算法不得读取 DUT 输出。状态使用 ref_；临时量按记录角色由程序统一命名，不能与端口/状态重名、自引用或代替跨拍状态。先扩位并明确符号，再运算与判界，最后截取。数学简写须与规格量等价：对数、置位数量与索引是不同量，不因函数名称相似而替代。逐个状态列全各控制事件的组合：无事件、各事件单独发生、同时发生、复位；每种组合明确保持/更新和优先级，不能只写会递增或置位的分支。事件是否接受按沿前状态判断；寄存输出建立独立状态，expected 读提交后的状态，组合输出按沿后状态计算，不重复累计当前输入。
5. 定向与随机刺激共用参考算法，不手填期望表。auto 模式由程序生成通用边界、随机输入与复位；只补规格专有的连续/暂停/同时操作，遗漏输入按0、复位无效，不继承。显式模式则精确覆盖全部非时钟输入。values 不读取端口或状态，repeat 复用向量。
6. 格式/编译恢复共享一次机会，围绕原计划修正诊断所指结构，不重写无关算法。功能失配不修改期望；结构化流程另从规格与完整实际输入历史盲推期望，由程序比较双方结果，缺历史不猜。修复只接收绑定观测和规格依据，固定 TB 原样复验；独立推导及日志绑定仍不能证明语义正确，一次归因仅支持一次修复。
